# lean_protect

Легкий мод захисту територій для серверів Luanti. Мінімальне
навантаження навіть при тисячах гравців.

## Можливості

- Два маркери-палки (камінь + палиця) для вибору кутів
- `/protect <назва>` — створити область
- Захист від копання, ставлення, взаємодії, TNT
- Спільний доступ і передача власності
- HUD-індикатор (назва області + власник)
- Золоте підсвічування через `/protect_show`
- Краш-безпечність (залишки стін прибираються при старті)
- Українська локалізація

## Продуктивність

- **Fast path** у `is_protected`: ~0.3 мкс
- **CPU при 1000 гравцях**: ~1.3% одного ядра
- **Пам'ять на область**: ~200 байт
- **Запис на диск**: debounced (максимум раз на 2 сек)

Використовує spatial hash чанків, тому `is_protected` — O(1), а не O(N).

## Встановлення

1. Розпакуйте `lean_protect` у `games/<назва_гри>/mods/`.
2. Перезапустіть Luanti.

Потрібен Luanti 5.8+ і мод `default`.

## Використання

### Крафт маркерів

```
Маркер #1        Маркер #2
[     ]          [     ]
[палиця]         [камінь]
[камінь]         [палиця]
```

### Створення області

1. Клікніть маркером #1 по одному куту.
2. Клікніть маркером #2 по протилежному куту.
3. Введіть `/protect myhome`.

### Команди

| Команда | Опис |
|---|---|
| `/protect <назва>` | Створити область з виділення |
| `/protect_list` | Список ваших областей |
| `/protect_info` | Показати бюджет |
| `/protect_show [назва]` | Підсвітити область на 15 сек |
| `/protect_remove <назва>` | Видалити область |
| `/protect_cancel` | Очистити виділення |
| `/protect_add <область> <гравець>` | Дати доступ |
| `/protect_remove_member <область> <гравець>` | Забрати доступ |
| `/protect_members <область>` | Список учасників |
| `/protect_rename <стара> <нова>` | Перейменувати |
| `/protect_transfer <область> <гравець>` | Передати власність |
| `/protect_help` | Показати всі команди |
| `/protect_cleanup` | Прибрати залишки стін (адмін) |

### Ліміти

- 3 області на гравця
- 10 000 блоків загального бюджету
- Без перетинів з існуючими областями
