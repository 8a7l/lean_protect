# lean_protect

Легкий мод захисту територій для серверів Luanti. Мінімальне
навантаження навіть при тисячах областей і гравців.

## Можливості

- Два маркери-палки (камінь + палиця) для вибору кутів
- `/protect <назва>` — створити область
- Захист від копання, ставлення, взаємодії, TNT
- Спільний доступ і передача власності
- HUD-індикатор (назва області + власник)
- Золоте підсвічування через `/protect_show`
- Краш-безпечність (залишки стін прибираються при старті)
- Адмін-команди з привілеєм `protection_admin`
- Привілей `protection_bypass` для модераторів
- Українська локалізація

## Продуктивність

| Метрика | Значення |
|---|---|
| Fast path у `core.is_protected` | ~0.3 мкс (нема областей у чанку) |
| Slow path (влучання в область) | ~2 мкс |
| CPU при 1000 гравцях, 5000 областей | ~1.3% одного ядра |
| Пам'ять на область | ~200 байт |
| Запис на диск | debounced (макс. 1 запис / 2 сек) |
| Шардів у storage | 16 (`data_0` … `data_15`) |
| Показ стін | 1 VoxelManip-виклик на область |

Ключові рішення:

- **Spatial hash чанків** — `is_protected` працює за O(1), а не O(N).
- **16 шардів** — збереження однієї області торкається ~1/16 даних.
- **VoxelManip для стін** — у 20 разів швидше за `set_node` на великих областях.
- **Без globalstep для storage** — debounce через `minetest.after`.
- **Без метаданих на стінах** — нуль записів у SQLite під час preview.

## Встановлення

1. Розпакуйте `lean_protect` у `games/<назва_гри>/mods/`.
2. Перезапустіть Luanti.

Потрібен Luanti 5.5+ (VoxelManip) і мод `default`.

## Використання

### Крафт маркерів

```
Маркер #1        Маркер #2
[     ]          [     ]
[палиця]         [камінь]
[камінь]         [палиця]
```

### Створення області

1. Клікніть маркером #1 по одному куту.
2. Клікніть маркером #2 по протилежному куту.
3. Введіть `/protect myhome`.

### Команди

| Команда | Опис |
|---|---|
| `/protect <назва>` | Створити область з виділення |
| `/protect_list` | Список ваших областей |
| `/protect_info` | Показати бюджет |
| `/protect_show [назва]` | Підсвітити область на 15 сек |
| `/protect_remove <назва>` | Видалити область |
| `/protect_cancel` | Очистити виділення |
| `/protect_add <область> <гравець>` | Дати доступ |
| `/protect_remove_member <область> <гравець>` | Забрати доступ |
| `/protect_members <область>` | Список учасників |
| `/protect_rename <стара> <нова>` | Перейменувати |
| `/protect_transfer <область> <гравець>` | Передати власність |
| `/protect_help` | Показати всі команди |
| `/protect_cleanup` | Прибрати залишки стін (адмін) |

### Адмін-команди

Потребують привілею `protection_admin`.

| Команда | Опис |
|---|---|
| `/protect_admin_list <гравець>` | Список областей будь-якого гравця |
| `/protect_admin_remove <гравець> <область>` | Примусово видалити |
| `/protect_admin_rename <гравець> <стара> <нова>` | Перейменувати |
| `/protect_admin_transfer <гравець> <область> <новий_власник>` | Примусово передати |
| `/protect_admin_count` | Статистика по всьому серверу |

### Привілеї

| Привілей | Призначення |
|---|---|
| `protection_admin` | Повний доступ: керування областями, обхід захисту та відкриття контейнерів (скринь, печей) будь-де. |
| `protection_bypass` | Доступ будівельника: дозволяє копати/ставити блоки, але **не дозволяє** відкривати контейнери на чужій території. |

## Ліміти

- 3 області на гравця
- 10 000 блоків загального бюджету на гравця
- Мінімум 1 000 блоків на область
- Без перетинів з існуючими областями

## Зберігання

Області лежать у `mod_storage` (SQLite за замовчуванням) як 16 шардів:

```
data_0   data_1   …   data_15     # дані областей, id % 16
next_id                            # монотонний лічильник id
schema                             # версія схеми
```

Кожен шард — JSON-об'єкт з рядковими ключами. Збереження однієї
області торкається лише її шарду. Стара схема з одним ключем (`data`)
мігрується автоматично при першому запуску цієї версії.

## Налаштування

Змінюються у `minetest.conf` або через меню розширених налаштувань:

| Налаштування | За замовчуванням | Опис |
|---|---|---|
| `lean_protect_max_areas_per_player` | 3 | Макс. областей на гравця |
| `lean_protect_max_volume_per_player` | 10000 | Макс. блоків на гравця |
| `lean_protect_min_volume_per_area` | 1000 | Мінімальний розмір області |
| `lean_protect_save_interval` | 2.0 | Інтервал збереження (сек) |
